# Open the website on Windows

1. Open this project folder in File Explorer.
2. Double-click `index.html` to open the website in your web browser.
3. If Windows asks which app to use, choose Microsoft Edge, Google Chrome, or Firefox.

No installation or build command is needed. The page includes its styles and scripts.
After editing and saving `index.html`, refresh the browser to see your changes.

To get a fresh copy from GitHub, select **Code > Download ZIP** on the repository page,
right-click the downloaded ZIP file, choose **Extract All**, and open `index.html`
inside the extracted folder.

Uploading files to GitHub stores the project. To view this copy of the website,
open the downloaded `index.html` as described above.
