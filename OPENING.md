# Open your pink website on Windows

## Open the live website on a phone or computer

https://dqaminh.github.io/Logistics-Introduction/

Send this link through Messenger. No download or GitHub account is needed.

## Open the files on your computer

1. Open this project folder in File Explorer.
2. Double-click `index.html`.
3. If Windows asks which app to use, choose Microsoft Edge, Google Chrome, or Firefox.

No installation, account, or build command is needed. It works offline too.
Keep the files and the `assets` folder together.

## Try the buttons

- **Em không giận anh** runs away when approached with a mouse, clicked, or tapped on a phone. You can also select it with Tab and press Enter or Space.
- **Em giận anh đó** opens `page2.html`.
- The second page has a little apology, a hug animation, and a link back.

## Make it yours

Right-click a file, choose **Open with > Notepad**, edit, then save as UTF-8.
Refresh your browser after saving.

- `index.html`: the first question and button text.
- `page2.html`: the second page's message.
- `styles.css`: the white and pink colors, rounded buttons, and layout.
- `script.js`: the runaway button and hug animation.
- `assets/love-cats.png`: the cat illustration.

The original README is preserved. The previous logistics website is saved in
`archive/logistics.html` and can still be opened by double-clicking it.

## Download from GitHub

On the repository page, select **Code > Download ZIP**. Right-click the ZIP,
choose **Extract All**, then open `index.html` in the extracted folder.
To share the files, send the entire ZIP so the picture and second page are included.

GitHub Pages publishes this repository's `main` branch. After you save your edits,
commit and push them to GitHub to update the live website. Publishing can take a
few minutes; the website address stays the same.
